# Записи капитана

Подключены 18 готовых мужских реплик: по шесть на русском, казахском и английском. Они заранее синтезированы локально Piper и записаны в MP3. Во время игры нет ни `speechSynthesis`, ни обращения к API генерации. Источники, лицензии и обработка перечислены в `../CREDITS.txt`.

Чтобы заменить голос собственными записями, замените соответствующие MP3:

| Файл | Реплика |
| --- | --- |
| `ru/laugh.mp3` | Ха-ха! |
| `ru/salute.mp3` | Привет, капитан! |
| `ru/oops.mp3` | Ой, промах! |
| `ru/luck.mp3` | Попутного ветра! |
| `ru/storm.mp3` | Надвигается буря! |
| `ru/gg.mp3` | Хорошая игра! |

Пожелания к записи: взрослый мужской голос, низкий, слегка хриплый, выразительный; длительность примерно 0,5–2 секунды, без музыки, длинной тишины и перегруза. Используйте свои записи или записи с разрешением на использование.

В `src/emotions/voices.json` замените `null` для нужного языка и ID на URL, например `"salute": "/audio/emotions/ru/salute.mp3"`. Затем выполните `npm run build` и загрузите всю `dist` в Netlify. Для казахского и английского — те же шесть имён в папках `kk` и `en`; тексты реплик находятся в `src/emotions/catalog.ts`. Пока запись не подключена, играет сигнал. Если подключённый файл повреждён или отсутствует, используется сигнал; запрет автоматического воспроизведения браузером не обходится. Никакой платный API не нужен.
