# Флот: Сектор 10

Браузерный морской бой против бота. React, TypeScript, Vite, Three.js и React Three Fiber. Все корабли процедурные; внешних моделей, изображений, текстур, шрифтов и звуков нет.

## Запуск

Требуется Node.js 20.19+ или 22.12+ и npm.

```sh
npm install
npm run dev
```

Откройте адрес, показанный Vite (обычно http://127.0.0.1:5173).

```sh
npm test          # тесты правил и полных партий
npm run test:e2e # сценарии браузера и снимки экранов (нужен установленный Chrome)
npm run build    # проверка TypeScript и production-сборка
npm run preview  # просмотр production-сборки
```

## Как играть

Выберите тип корабля в панели, при необходимости нажмите «Повернуть корабль», затем клетку своего поля. Корабль занимает клетки вправо либо вниз от выбранной. Между кораблями нужен зазор в одну клетку, в том числе по диагонали. «Авторасстановка» размещает весь флот, кнопка сброса очищает поле. После размещения всех десяти кораблей нажмите «Начать операцию».

Стреляйте по полю противника. Попадание сохраняет ход; промах передаёт его. Светлая точка означает промах, оранжевая звезда — попадание, заштрихованные клетки с крестом и открытым кораблём — потопление. Последняя атакованная клетка выделена светлой рамкой. Побеждает уничтоживший все корабли. Бот выбирает из неатакованных клеток и проверяет соседей после попадания; расположение флота ему при выборе не передаётся.

На телефоне переключайтесь между своим полем и противником вкладками. Выберите клетку, затем подтвердите расстановку или выстрел большой кнопкой под полем. Тип корабля и поворот доступны над полем. «Крупные клетки» увеличивают поле до размера, при котором каждая цель не меньше 44 px по высоте; увеличенное поле можно сдвигать горизонтально. На компьютере действие выполняется сразу по нажатию клетки.

Кнопка с процессором в шапке переключает «Живое море» / «Спокойное море». В спокойном режиме отключена постоянная перерисовка, рябь и частицы, плотность пикселей ограничена 1. На узком экране он включён по умолчанию. Системная настройка `prefers-reduced-motion` принудительно отключает анимацию независимо от переключателя. Статичные результаты выстрелов всегда остаются видимыми.

Партия автоматически сохраняется в localStorage, ключ `fleet-sector-10:v1`, версия формата `1`. После обновления продолжается и ход бота. При запрете хранилища игра работает без сохранения и показывает предупреждение. Повреждённые или несовместимые сохранения сбрасываются. Новая игра заменяет сохранение после подтверждения.

## Устройство проекта

- `src/game.ts`: правила, координаты, генерация флота, бот, проверка сохранений; не зависит от React/Three.js.
- `src/App.tsx`: интерфейс, жизненный цикл партии, таймер бота и сохранение.
- `src/Board.tsx`: ортографическая 3D-сцена, эффекты, увеличение и доступные кнопки клеток.
- `src/scene/Vessel.tsx`: четыре процедурные модели с надстройками, орудиями, радарами и авиацией.
- `src/scene/Ocean.tsx`: анимированная вода без текстур; геометрия моря плоская, проекция клеток не искажается.
- `src/useMedia.ts`: подписка на сенсорный ввод, размер экрана и уменьшение движения.
- `src/game.test.ts`: расстановка, выстрелы, очередность, победа, бот, восстановление и полные партии.
- `e2e/game.spec.ts`: сценарии реального браузера для широкого и мобильного экранов.

Модели не выходят за занимаемые клетки. DOM-сетка совпадает с проекцией моря; корабли скрыты от интерфейса противника до потопления. Приложение полностью локальное, поэтому это визуальное сокрытие, а не защита от просмотра данных через инструменты разработчика.

## Проведённые проверки

Тесты Vitest проверяют 50 автоматических расстановок, 5 полных партий ботов и основные правила. Браузерные сценарии запускаются в отдельном Chrome через Playwright и управляют настоящими кнопками интерфейса. Для воспроизводимого теста попаданий и завершения используется известная корректная расстановка через штатный формат сохранения; обычная ручная расстановка проверяется отдельным сценарием.

Сценарии покрывают ручную расстановку всех кораблей, поворот, запрет касания, сброс и авторасстановку; промах, ход бота, попадание, потопление, победу, поражение, новую игру; восстановление расстановки, боя, хода бота и завершённой партии. Проверяются сенсорное подтверждение, увеличение клеток, отсутствие горизонтального переполнения страницы и уменьшение движения. Скриншоты сохраняются в `artifacts/` (папка исключена из Git): `desktop-setup.png`, `desktop-fleet.png`, `desktop-hit.png`, `desktop-sunk.png`, `desktop-victory.png`, `desktop-defeat.png`, `mobile-setup.png`, `mobile-battle.png`.

Vite предупреждает о размере основного JS-пакета (около 1,15 МБ до gzip / 321 КБ gzip), в который входит Three.js. Это не ошибка сборки.

## Ограничения первой версии

Одиночная игра, простой бот без уровней сложности, фиксированная камера. Эффекты короткие и не блокируют ход; звука нет. Для отображения кораблей нужен WebGL. На телефоне поля переключаются вкладками. Нет регистрации, сети, магазина и платежей. Хранилище ограничено текущим браузером и адресом приложения. Проверки Chrome с эмуляцией касаний не заменяют замеры производительности на реальном слабом телефоне.
