# Флот: Сектор 10

Браузерный «Морской бой» в трёхмерном сумеречном архипелаге. Для студентов, друзей и всех, кому нужна короткая тактическая партия без установки приложения.

**[Играть на сайте](https://flot-sector.netlify.app/)** · **[Как играть](https://flot-sector.netlify.app/?view=guide)** · **[Исходный код](https://github.com/talgat-code/battleship)**

## Что можно делать

- Играть гостем против бота: три сложности, ручная и автоматическая расстановка, продолжение после обновления страницы.
- Зарегистрировать логин и пароль, сохранять профиль, валюту, покупки и результаты в Supabase. Старые аккаунты поддерживают вход по почте.
- Пригласить друга по ссылке: сервер проверяет ходы и скрывает флот противника. Есть реванш, отдельный сетевой рейтинг и приватный чат комнаты.
- Использовать пять способностей против бота и шесть бесплатных эмоций. Морской фон, эффекты и записанные реплики можно отключать отдельно.
- Играть на компьютере или телефоне; доступны увеличенные клетки, уменьшение движения и интерфейс RU / KZ / EN (часть сетевого интерфейса пока на русском).

Особенность проекта — процедурные корабли и живое море с островами, маяком и акулами; интерфейс и анимация отделены от правил. Бот выбирает выстрелы по известным результатам, не читая скрытые корабли.

## Правила и первый запуск игры

На поле 10×10 размещаются 10 прямых кораблей: один на 4 клетки, два на 3, три на 2 и четыре на 1. Корабли не соприкасаются даже углами. Попадание сохраняет ход, промах передаёт его; повторный выстрел запрещён. Побеждает тот, кто первым уничтожит все 20 сегментов. Крестики вокруг потопленных кораблей — подсказки, а не выстрелы.

**С ботом:** «Играть с ботом» → выбрать сложность → расставить флот → начать бой. **С другом:** войти в два разных аккаунта → создать комнату → передать приглашение → подтвердить расстановку обоим. Чат находится под полями, история сохраняется в комнате. Сетевой бой в текущем развёртывании классический, без карт способностей.

## Запуск проекта

Нужны Node.js 22+ и npm.

```sh
npm ci
npm run dev
```

Адрес разработки: `http://127.0.0.1:5173`. Для аккаунтов скопируйте `.env.example` в `.env.local` и задайте `VITE_SUPABASE_URL` и `VITE_SUPABASE_PUBLISHABLE_KEY` своего проекта. Без них доступен гостевой бой. `.env.local` исключён из Git; административные ключи в Vite запрещены.

Сервер: [настройка входа и Supabase](supabase/LOGIN_DEPLOYMENT.md), [подключение чата](supabase/ROOM_CHAT.md). Проверяйте существующую схему через `supabase/check_schema.sql`; не применяйте миграции повторно вслепую. Чат (009) работает без необязательной миграции 008.

```sh
npm test
npm run test:e2e
npm run build
npm run preview
```

Браузерные тесты используют установленный Chrome. Реальные серверные сценарии требуют явного включения: `$env:CLASSIC_LIVE='1'`, затем `npx playwright test e2e/classic-live.spec.ts` в PowerShell; они создают тестовые аккаунты и матч в настроенном Supabase. Остальные тесты не заменяют такую проверку.

**Netlify Drop:** после сборки загрузите всю папку `dist`, включая `_redirects` и ресурсы. Переменные `VITE_*` нужны во время сборки. Push в GitHub сам по себе не обновляет Drop-сайт; SQL и Edge Function развёртываются отдельно от `dist`.

## Технологии, AI и материалы

- React, TypeScript, Vite, Three.js / React Three Fiber; Supabase Auth и PostgreSQL с RLS; иконки Lucide.
- Vitest — правила и сохранение; PGlite — настоящий SQL и права доступа; Playwright — браузерные сценарии, два аккаунта и мобильная вёрстка.
- OpenAI Codex использован для разработки, диагностики и тестов; ChatGPT — для иллюстраций, предоставленных автором проекта. Голосовые реплики подготовлены заранее с помощью Piper, без платного API во время игры.
- Корабли, ландшафт и вода создаются кодом; готовые 3D-модели не загружались. Заимствованные аудиоматериалы, голоса и лицензии перечислены в [audio/CREDITS.txt](public/audio/CREDITS.txt); лицензии шрифта — в `public/licenses`. Исходные фон моря, выстрел и PNG предоставлены владельцем проекта; их права следует проверить перед коммерческим использованием.
