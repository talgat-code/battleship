Инструкция ниже — для отсутствующей схемы, повторно применять её на этом проекте не нужно.

## Применение к существующему проекту

В Supabase SQL Editor сначала проверьте:

```sql
select to_regclass('public.duel_chat_messages'),
       to_regclass('public.duel_chat_limits'),
       to_regprocedure('public.fleet_chat(jsonb)');
```

Если все три объекта отсутствуют, выполните **целиком** файл `supabase/migrations/202610010009_room_chat.sql`. Если есть только часть объектов, сначала сравните схему, не удаляйте данные. Если все присутствуют и совпадают с миграцией, повторять её не нужно. Авторизованный CLI вместо SQL Editor:

```powershell
npx --yes supabase db query --linked --project-ref ztimlpcqwbsxqfmetbpe --file supabase/migrations/202610010009_room_chat.sql --output json
```

После применения соберите `npm run build` и загрузите всю новую `dist` в Netlify Drop. Дополнительные секреты и Edge Functions для чата не нужны. Не запускайте `db push` по всем историческим миграциям этого проекта.

## Проверяемые гарантии

- RLS включён; прямой доступ к таблицам и их sequence закрыт для `anon` и `authenticated`. Узкий SECURITY DEFINER RPC проверяет `auth.uid()` и членство в комнате на каждом чтении/отправке.
- Отправитель, время и раунд назначаются сервером. По одному ID комнаты посторонний не читает переписку. Сообщения не содержат скрытый флот.
- UUID отправки сохраняется до подтверждения; повтор после сетевой ошибки не добавляет дубль. Пауза 2 секунды проверяется под блокировкой для пользователя во всех комнатах.
- 1–300 символов, только текст; React экранирует HTML. В комнате сохраняется история всех раундов, клиент начинает с последних 50 сообщений и догружает новые по курсору.
- Обновления идут через авторизованный RPC каждые 2,5 секунды, без публичных Realtime-каналов; в скрытой вкладке опрос приостанавливается. Краткий обрыв не отменяет бой.

Проверки: `npm test` (SQL/RLS), `npx playwright test e2e/chat.spec.ts` (интерфейс с HTTP-фикстурой), `$env:CLASSIC_LIVE='1'` и `npx playwright test e2e/classic-live.spec.ts` (два настоящих аккаунта, чат и полный матч). Последний тест создаёт записи на сервере; не запускайте его при каждой сборке.
